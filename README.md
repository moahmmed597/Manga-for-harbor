# مستودع المانجا لتطبيق هاربورد (Manga for Harbor)

مستودع مخصص حصرياً للمانجا والمانهوا والأنمي (عربي وإنجليزي) مصمم ليعمل 100% على تطبيق Harbor على التلفزيون (Samsung Tizen) والكمبيوتر.

## رابط الإضافة في تطبيق Harbor:
```text
https://raw.githubusercontent.com/moahmmed597/Manga-for-harbor/main/repo.json
```

## المصادر المشمولة والمفحوصة (100% شغالة):
### المصادر العربية:
1. **مانجا العاشق (3asq)**: أشهر وأكبر موقع عربي لترجمة المانجا الشهيرة مثل ون بيس، كينجدوم، وغيرها.
2. **Team-X (عربي)**: فريق تيم إكس لأشهر أعمال المانهوا والمانجا المترجمة بالعربية.
3. **AzoraFly (عربي)**: شبكة أزورا مانجا لأحدث أعمال المانهوا والمانجا الحصرية.
4. **مانجا اون لاين (عربي)**: مكتبة ضخمة تضم آلاف الأعمال وفصول المانجا المترجمة.

### المصادر الإنجليزية:
5. **MangaPill (English)**: مصدر سريع وخالي من الإعلانات يضم أحدث فصول المانجا فور صدورها بجودة عالية.
6. **Manganato (English)**: أضخم أرشيف مانجا عالمي يضم ملايين الفصول وآلاف السلاسل المكتملة والمستمرة.

جميع الإضافات مفحوصة ومجربة وتدعم:
- تصفح الأحدث والشائع (Popular)
- عرض قائمة الفصول (Chapters)
- استخراج وقراءة كامل الصفحات عالية الدقة (Pages)
