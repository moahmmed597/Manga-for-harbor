# مستودع المانجا لتطبيق هاربور (Manga for Harbor) - الإصدار 3.0.0

مستودع شامل ومخصص حصرياً للمانجا والمانهوا والويب تون (عربي وإنجليزي)، يجمع أقوى مصادر فرق الترجمة العربية الموثوقة والمكتبات العالمية، ومفحوص ليعمل 100% وبدون أي شاشات سوداء أو حجب Cloudflare على تطبيق Harbor في تلفزيونات سامسونج (Tizen) وجميع الأجهزة.

## رابط الإضافة المباشر في Harbor:
```text
https://raw.githubusercontent.com/moahmmed597/Manga-for-harbor/main/repo.json
```

## المصادر المشمولة والمفحوصة (9 مصادر تعمل 100%):

### المصادر العربية (6 مصادر ضخمة):
1. **مانجاتك - MangaTuk (عربي)**: مصدر عربي ضخم وجديد يحتوي على أكثر من 2,000 سلسلة مانجا ومانهوا مترجمة للعربية بسيرفرات صور سريعة ونقية بصيغة WebP.
2. **مانجا دكس - MangaDex (عربي)**: أكبر أرشيف مانجا مفتوح عالمياً مفلتر بالكامل لترجمات الفرق العربية (ون بيس، ون بنش مان، بيرسيرك، داندادان، طوكيو ريفينجرز وغيرها) عبر شبكة سيرفرات MangaDex @Home المباشرة.
3. **مانجا العاشق (3asq)**: المصدر الرسمي لفريق العاشق لأقوى سلاسل المانجا مثل ون بيس وكينجدوم وهجوم العمالقة.
4. **Team-X (تيم إكس)**: السيرفر الأساسي لفريق Team-X لأعمال المانهوا الكورية والمانجا الحصرية.
5. **AzoraFly (أزورا مانجا)**: مكتبة أزورا الضخمة للمانهوا الكورية والمانجا والويبتون المترجمة.
6. **مانجا اون لاين (Onma)**: أرشيف ضخم يضم آلاف السلاسل والفصول القديمة والحديثة بترجمة عربية.

### المصادر الإنجليزية (3 مصادر عالمية):
7. **ComicK Manga**: مكتبة المانجا والمانهوا العالمية الرائدة مع تصنيفات دقيقة وقراءة سلسة.
8. **MangaPill**: مصدر إنجليزي فائق السرعة وخالي من التعليق لأحدث الفصول فور نزولها.
9. **Manganato**: أضخم مكتبة مانجا إنجليزية تضم آلاف السلاسل الكاملة.
