# مستودع المانجا لتطبيق هاربورد (Manga for Harbor)

مستودع شامل ومخصص حصرياً للمانجا والمانهوا (عربي وإنجليزي) يجمع كافة إضافات مستودع خويك (Arabic Scans) والمكتبات الموثوقة الأخرى، ومفحوص ليعمل 100% على تطبيق Harbor على التلفزيون (Samsung Tizen) والكمبيوتر.

## المصادر المشمولة والمفحوصة (100% شغالة):

### المصادر العربية (شاملة جميع إضافات خويك):
1. **مانجا العاشق (3asq)**: المصدر الرسمي لفريق العاشق لأقوى سلاسل المانجا مثل ون بيس وكينجدوم.
2. **Team-X (تيم إكس)**: السيرفر الأساسي لفريق Team-X لأعمال المانهوا والمانجا الحصرية.
3. **AzoraFly (أزورا مانجا)**: مكتبة أزورا الضخمة للمانهوا الكورية والمانجا المترجمة.
4. **مانجا اون لاين**: أرشيف ضخم يضم آلاف السلاسل والفصول القديمة والحديثة.

### المصادر الإنجليزية:
5. **ComicK Manga**: مكتبة المانجا والمانهوا العالمية الرائدة مع تصنيفات دقيقة وقراءة سلسة.
6. **MangaPill**: مصدر إنجليزي فائق السرعة وخالي من التعليق لأحدث الفصول فور نزولها.
7. **Manganato**: أضخم مكتبة مانجا إنجليزية تضم ملايين الفصول وآلاف السلاسل الكاملة.

جميع المصادر تعمل 100% بدون أي حاجة لمستودعات أخرى!
